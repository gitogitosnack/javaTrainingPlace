# continue文とは？

`continue`文は、ループ（`for`, `while`, `do-while`）の中で使う制御構文で、**その回のループ処理を途中で打ち切り、次の周回（次のループ）へスキップする**ためのものです。

`break`が「ループ全体を抜ける」のに対し、`continue`は「**今回だけスキップして、ループ自体は継続する**」という違いがあります。既存コードで「特定の条件だけ処理をスキップしている」ループを見つけたら、`continue`が使われていないか確認するのがポイントです。

### 🏭 イメージ：「不良品だけをはじく検品ライン」

1. **ループ開始（ベルトコンベアが流れる）**
   - 配列やリストの要素を1つずつ処理していく。
2. **条件チェック（不良品判定）**
   - 特定の条件（例：不要なデータ）に該当したら`continue`を実行する。
3. **スキップして次へ（ラインは止まらない）**
   - `continue`以降の処理は実行されず、**すぐに次の周回の条件式・更新式へ進む**。ループ自体は終了しない。

---

## ✨ break との違い

| 構文       | 効果                                           | イメージ                             |
| :--------- | :--------------------------------------------- | :----------------------------------- |
| `break`    | ループを**完全に終了**する                     | ラインそのものを止める               |
| `continue` | **今回の処理だけ**スキップし、ループは継続する | 不良品だけを弾いてラインは流し続ける |

---

## 📝 使い方

| 種類           | 構文                                                 | 説明                                                                     |
| :------------- | :--------------------------------------------------- | :----------------------------------------------------------------------- |
| **基本形**     | `if (条件) { continue; }`                            | 条件に合致した場合のみ、以降の処理をスキップする。                       |
| **ラベル付き** | `outer: for (...) { for (...) { continue outer; } }` | 二重ループで、**外側のループの次の周回**へスキップする（多用は非推奨）。 |

### 🛠️ コード例

```java
public class ContinueExample {
    public static void main(String[] args) {
        String[] names = {"Taro", "", "Hanako", null, "Jiro"};

        for (String name : names) {
            // 空文字またはnullの場合は、このデータの処理をスキップして次へ進む
            if (name == null || name.isEmpty()) {
                continue;
            }
            System.out.println("Hello Mr./Ms. " + name);
        }
        // 出力: Hello Mr./Ms. Taro / Hello Mr./Ms. Hanako / Hello Mr./Ms. Jiro
        // （空文字とnullの回は出力されずにスキップされる）
    }
}
```
