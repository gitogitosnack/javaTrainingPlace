# Java Stream APIとは？

Java 8で導入されたStream API（ストリームAPI）は、**コレクション（ListやSetなど）や配列**といったデータ群に対して、**簡潔かつ柔軟に関数型スタイルでデータ処理**を行うための仕組みです。

従来の`for`ループによる煩雑な処理を、まるで\*\*工場のベルトコンベア（パイプライン）\*\*のようにメソッドを繋げて記述できるのが最大の特徴です。

### 🏭 イメージ：「工場のベルトコンベア」

Stream APIを使ったデータ処理は、以下の3つのフェーズに分けることができます。

1.  **データの供給源（ソース）**
    - List、Set、配列などから`stream()`メソッドで**ストリームを生成**します。

2.  **中間操作（ベルトコンベアでの加工・選別）**
    - データが流れている途中で、**変換**や**絞り込み**などの処理を定義します。
    - 例: `filter`, `map`, `sorted` など。
    - **遅延実行**されるため、この時点ではまだ実際の処理は行われません。

3.  **終端操作（最終的な結果の取り出し）**
    - ストリームの処理を\*\*開始（実行）\*\*し、最終的な結果を取り出したり、副作用（例: 出力）を発生させたりします。
    - 例: `collect`, `forEach`, `count`, `reduce` など。
    - **終端操作はパイプラインにつき一度だけ実行**でき、実行後はそのストリームは**消費**されて再利用できません。

---

## ✨ Stream APIの主な特徴

| 特徴             | 説明                                                                                                                                                                                          |
| :--------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **宣言的記述**   | 「**何をしたいか**」（例: 偶数を抽出したい）を記述し、「**どのように処理するか**」という手続き的な記述（例: `for`ループのインクリメント）を減らせます。コードが**簡潔で読みやすく**なります。 |
| **パイプライン** | 中間操作をメソッドチェーンで繋げ、一連の流れ（パイプライン）として処理を記述できます。                                                                                                        |
| **遅延実行**     | 中間操作は、終端操作が呼び出されるまで実際の処理を保留します。これにより、不要な処理をスキップできるなど、**効率的な処理**が可能になります。                                                  |
| **非破壊的**     | ストリームは、元のデータソース（Listなど）を変更しません。結果は新しいコレクションとして生成されます。                                                                                        |
| **並列処理**     | `parallelStream()`メソッドを使用することで、簡単にデータを並列処理させることができ、マルチコアCPUの性能を活かして**パフォーマンスを向上**させることが可能です。                               |

---

## 📝 代表的なメソッド（処理）

| 種類     | メソッド    | 説明                                                  | 例                                   |
| :------- | :---------- | :---------------------------------------------------- | :----------------------------------- |
| **中間** | `filter()`  | 条件に合う要素のみを**絞り込む**。                    | `n -> n % 2 == 0` (偶数のみ)         |
| **中間** | `map()`     | 各要素を**別のものに変換**する。                      | `String::toUpperCase` (大文字に変換) |
| **中間** | `sorted()`  | 要素を**並び替える**。                                | `Comparator.naturalOrder()` (昇順)   |
| **終端** | `collect()` | 処理結果を**ListやSetなどのコレクションに集約**する。 | `Collectors.toList()`                |
| **終端** | `forEach()` | 各要素に対して**処理を実行**する（結果を返さない）。  | `System.out::println` (画面出力)     |
| **終端** | `count()`   | 要素の**個数**を数える。                              |                                      |

### 🛠️ コード例

```java
import java.util.Arrays;
import java.util.List;
import java.util.stream.Collectors;

public class StreamExample {
    public static void main(String[] args) {
        List<String> words = Arrays.asList("apple", "banana", "cat", "dog", "egg");

        // 処理の流れ：
        // 1. 文字列のリストからストリームを生成
        // 2. filter: 長さが3文字より長い単語のみを抽出 (Intermediate Operation)
        // 3. map: それらを全て大文字に変換 (Intermediate Operation)
        // 4. collect: 結果を新しいListに格納 (Terminal Operation)
        List<String> result = words.stream()
            .filter(w -> w.length() > 3)
            .map(String::toUpperCase)
            .collect(Collectors.toList());

        System.out.println(result);
        // 出力: [APPLE, BANANA]
    }
}
```

Stream APIは、現代のJavaプログラミングにおいて、コレクション処理を効率的かつ可読性高く記述するために必須の機能となっています。
