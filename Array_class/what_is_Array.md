# java.util.Arraysクラスとは？

Java標準ライブラリの`java.util.Arrays`クラスは、**配列（Array）を操作するための便利なメソッド**を集めた**ユーティリティクラス**です。

すべてのメソッドが**`static`（静的メソッド）**として提供されているため、インスタンス化（`new Arrays()`）せずに、`Arrays.メソッド名(...)`の形でそのまま呼び出せます。

### 🏭 イメージ：「配列専用の便利道具箱」

配列（`int[]`, `String[]`など）は、`List`のような便利なメソッド（`sort`, `contains`など）を持っていません。そこで、配列に対する**ソート・検索・比較・初期化・変換**といった定型処理を、`for`ループを自前で書かずに済むようにまとめたのが`Arrays`クラスです。

---

## ✨ なぜ`for`ループを書かずに`Arrays`クラスを使うのか

| 観点               | `for`ループで自前実装                                             | `Arrays`クラスを使用                                              |
| :----------------- | :----------------------------------------------------------------- | :------------------------------------------------------------------ |
| **可読性**         | ソートや比較のロジックが埋もれ、**何をしたいコードか読み取りにくい** | `Arrays.sort(arr)`のように**意図が一目で分かる**                    |
| **バグ混入リスク** | 境界値（`i <= length`など）のミスや、比較ロジックの誤りが起きやすい | JDKで**十分にテストされた実装**を使うため、境界値バグが起きにくい   |
| **保守性**         | 同じような処理があちこちに重複しがち                              | 標準APIなので**チーム全員が読み方を知っている**                     |

つまり、配列に対する定型処理は「車輪の再発明」をせず、`Arrays`クラスに任せるのが業務上の定石です。

---

## 🛠️ 代表的な使い方のコード例

```java
import java.util.Arrays;

public class ArrayBasicExample {
    public static void main(String[] args) {
        int[] numbers = {5, 3, 1, 4, 2};

        // ソート（昇順）
        Arrays.sort(numbers);

        // 配列の中身を文字列として出力（そのままprintlnすると参照値しか出ない）
        System.out.println(Arrays.toString(numbers)); // [1, 2, 3, 4, 5]
    }
}
```

配列は`System.out.println(numbers)`のようにそのまま出力すると`[I@1b6d3586`のような参照値が表示されてしまいますが、`Arrays.toString()`を使うことで**中身を可読な文字列**として確認できます。
